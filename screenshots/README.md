# Entertainment Marketing & Advertising Analytics

### Power BI | Marketing Analytics | Advertising Performance | Business Intelligence

An interactive Power BI dashboard exploring advertising performance across three fictional animation studios: **Dizzyland Studios, Marvellous Mayhem Studios, and PixelPop Animation**.

Built using an original synthetic dataset, this portfolio project demonstrates how advertising data can be transformed into actionable business insights to evaluate campaign effectiveness, identify performance drivers, and uncover opportunities for budget optimization.

## Project Overview

The project provides four complementary analytical perspectives:

- **Executive Overview:** Monitor advertising investment, attributed revenue, return on ad spend (ROAS), and performance trends.
- **Campaign Performance:** Explore the conversion journey and compare marketing effectiveness across channels and studios.
- **Campaign Deep Dive:** Investigate campaign-level advertising returns, conversion efficiency, and key performance drivers.
- **Budget Optimization:** Evaluate planned versus actual spending, budget utilization, and opportunities to improve campaign delivery.

## Dataset

The dashboard uses an original synthetic advertising dataset created specifically for this portfolio project.

| Dataset Attribute | Description |
|---|---|
| Industry | Entertainment & Advertising |
| Studios | 3 fictional animation studios |
| Campaigns | 240 |
| Advertising Channels | 6 |
| Reporting Period | 2024–2025 |
| Data Type | Synthetic |

All studios, characters, campaigns, and performance results are fictional.

## Key Performance Indicators

The dashboard supports analysis of key advertising and marketing performance metrics:

- **Advertising Spend:** Total advertising investment.
- **Attributed Revenue:** Revenue attributed to advertising campaigns.
- **ROAS:** Return on advertising spend.
- **Advertising Return %:** Advertising profitability relative to spend.
- **Impressions:** Total advertising impressions delivered.
- **Clicks:** Total clicks generated by advertising campaigns.
- **CTR:** Click-through rate.
- **Leads:** Total leads generated.
- **Click-to-Lead Rate:** Percentage of clicks resulting in leads.
- **Conversions:** Total completed conversion events.
- **Lead-to-Conversion Rate:** Percentage of leads resulting in conversions.
- **Budget Utilization %:** Actual advertising spend relative to planned budget.
- **Unspent Budget:** Remaining advertising budget.
- **Campaigns Under Budget %:** Percentage of campaigns spending below their allocated budgets.
- **Revenue YoY Growth %:** Year-over-year change in attributed revenue.

Interactive analysis supports exploration of budget utilization by studio, campaign, advertising channel, targeting strategy, and buying strategy.
